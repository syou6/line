## 説明文

```
■ あなたのメモを、あなただけのものに

「プライベートメモ」は、書いた内容を端末内で暗号化して保管するメモアプリです。
アカウント登録は不要。広告もトラッキングもありません。

■ 主な機能

・PINロック
  6桁のPINで解錠。PINはどこにも保存されないため、あなた以外は開けません。

・強力な暗号化
  メモはAES-GCMで暗号化。鍵はPINから導出され、端末の外に出ることはありません。

・Face ID / Touch ID
  生体認証でスムーズに解錠できます。

・タグ・検索・フォルダ・ピン留め
  タグ付けとキーワード検索、フォルダ分け、ピン留めで大事なメモをすぐ見つけられます。

・iCloud同期（暗号化）
  同期されるのは暗号化されたデータのみ。iCloud上でも内容は読めません。
  同じPINを設定した端末どうしで安全に共有できます。

・自動ロック
  アプリを離れると自動でロック。閉じ忘れの心配がありません。

・おとりPIN
  本来のPINとは別のPINを設定でき、そのPINでは切り離された別の保管庫が開きます。
  PINの入力を強要された場合などに、本来のメモを守るためのセキュリティ機能です。

・緊急消去
  すべてのデータをワンタップで完全に削除できます。

■ プライバシーについて

・開発者はあなたのメモを収集しません。読むこともできません。
・分析ツール・広告SDKは一切使用していません。
```

## App プライバシー（App Privacy 質問票）

前提: 本アプリは分析・広告SDKなし、開発者サーバなし。
iCloud同期は **ユーザー自身のプライベートCloudKitデータベース** に暗号文を保存するもので、
開発者はアクセスできない。

- 「このAppからデータを収集していますか？」→ **いいえ（Data Not Collected）**

> 注: CloudKitプライベートDBへの保存は、開発者がアクセス・利用しないため
> Appleの定義では「収集」に該当しません（App Privacy Details のガイダンス参照）。
> 将来、分析SDK等を入れる場合はこの回答を見直すこと。

## 輸出コンプライアンス（暗号化）

- 「暗号化を使用していますか？」→ **はい**
- 「Appleの標準暗号（CryptoKit/CommonCrypto等）のみ？」→ **はい（免除対象）**
- `ITSAppUsesNonExemptEncryption = false` は設定済み（project.yml）。
- 年次のセルフ分類レポート（米国輸出規制）が必要になる場合があります。

## 審査メモ（App Review Notes に貼る）

```
本アプリはローカル暗号化メモアプリです。

【動作確認手順】
1. 初回起動でPIN（6桁）を設定してください（例: 111111）。
2. メモの作成・タグ・フォルダ・ピン留め・検索をお試しいただけます。
3. 設定 > おとり保管庫 から別PIN（例: 222222）を設定すると、
   そのPINでは本来とは別の保管庫が開きます。これはPINの開示を強要された際に
   ユーザーのデータを守る「デュレス（duress）PIN」と呼ばれる一般的なセキュリティ機能です。

【プライバシー】
- サーバは所有しておらず、データ収集は一切ありません。
- iCloud同期はユーザーのプライベートCloudKit DBに暗号文のみを保存します。
```

## プライバシーポリシー テンプレート

そのまま静的ページとして公開できる文面:

```
プライバシーポリシー — プライベートメモ

最終更新日: <日付>

1. データの収集について
   本アプリは、個人情報を含む一切のデータを収集しません。
   アクセス解析・広告・トラッキングの仕組みを含みません。

2. データの保存について
   作成されたメモはお使いの端末内で暗号化されて保存されます。
   iCloud同期を有効にした場合、暗号化されたデータのみが
   お客様自身のiCloudアカウント（プライベートデータベース）に保存されます。
   開発者がその内容にアクセスすることはできません。

3. 生体認証について
   Face ID / Touch IDは端末内の認証にのみ使用され、
   生体情報がアプリや開発者に渡ることはありません。

4. お問い合わせ
   <メールアドレス>
```
